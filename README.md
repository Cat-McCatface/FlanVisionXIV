For proper use, disable anti-aliasing in game (due to use of overriding AA shader effect).

Have in game gamma correction as low as possible for your display type (IPS/VA/OLED).

Known issues: during full moons, ground and sky will be unnaturally bright. this is because SE has the moon as a light source and does now know subtlety as seen in use of bloom shader efx everywhere, including said moon light source.

New as of 28 October, 2026: As of patch 7.5x if back-buffer options have been altered in reshade, KeepUI may cause map flags to be duplicated (once) visually. This effect is minor but was enough to need to wipe (reshade) and reinstall to test.
